# goatgrass
Code &amp; Supplementary material  for Nelson, Dritz, Aigner, Harrison &amp; Valdovinos in Submission. 

Data & code Zip file contains sample code, raw data, metadata & supplementary materials for goatgrass experimental.
Goatgrass simulation folders contains matlab code for goatgrass simulations & consumer-resource model.
gg_simulation_clean.R and associated .csv files provides code for interpreting and visualizing simulation results in R.
LACA_networks_for_paper.R and laca_full.csv provide summary data and code for landscape-level observational study of pollinator networks. 
For questions about data curation, contact Dr. Rebecca Nelson (becca.nelson@usu.edu; ranelson526@gmail.com).

Raw data from observational study and further site details are stored in repositories associated with Nelson, Williams, Valdovinos & Harrison in submission and can be found at:
